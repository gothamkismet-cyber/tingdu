# AI 语音与联网使用说明

听读 2.5 增加了可选的 AI 语音。你需要自己准备 API 服务、密钥、音频模型和音色；软件不附带共享密钥，不代购额度。原来的设备语音和本地练习仍可直接使用。

## 连接一次，先试听

1. 打开左侧或底部的「AI 语音」，展开「连接自己的语音 AI」。也能从「声音与备份」进入。
2. 填写 API 根地址、API 密钥、音频模型、音色。
3. 点击「保存并测试语音」。只有收到格式有效的 WAV 音频，才会启用陪练和生成听力。展开连接设置，可以播放测试音频。
4. 想把普通单词和听力题也交给 AI 朗读，勾选「单词和听力题也使用 AI 朗读」。取消勾选即可恢复设备语音。

这里的 API 是服务商提供的调用入口。默认配置示例：

| 项目 | 示例 / 要求 |
| --- | --- |
| API 根地址 | `https://api.openai.com/v1`；第三方兼容服务填写其文档给出的根地址 |
| API 密钥 | 你自己在服务商处创建的密钥，不要发到 GitHub 或聊天截图中 |
| 音频模型 | 默认示例 `gpt-audio-1.5`；以你的服务商实际开放的模型名称为准 |
| 音色 | 默认示例 `alloy`；必须是该模型支持的音色名称 |

根地址末尾不要重复写 `/chat/completions`。正式服务使用 HTTPS；Windows 和本机浏览器允许 HTTP 回环地址用于本机开发，Android 只接受 HTTPS。

兼容服务需要支持 `POST /chat/completions`、`input_audio` 的 WAV 输入、`modalities: ["text", "audio"]`，并在 `choices[0].message.audio.data` 返回 Base64 WAV。文字转语音专用接口 `/audio/speech`、仅文字聊天模型、只返回 MP3 或音频链接的服务，不能直接用于本版本。生成听力还要求同一模型接受纯文字输出。

测试会发送一段短静音音频和固定问候请求。通过表示接口接受了这些音频参数并返回有效音频；不能证明服务实际识别了录音，也不能代替音质和口音试听。请求了美式或英式发音时，实际效果由模型决定。协议依据：[OpenAI 音频对话文档](https://developers.openai.com/api/docs/guides/audio-chat-completions)。

## 文字与录音陪练

在顶部选择英语或日语，再输入一句话、点击「发送文字」。AI 会返回可播放的声音和回复文字；音频未自动播放时，点击播放器的播放按钮。

录音的操作是「录音 → 结束录音 → 本机预听 → 发送录音给 AI」。单段最多 30 秒，停止后释放麦克风；没有点击发送时，录音留在本机。也可丢弃并重录。发送录音时，输入框中的文字会作为同一条消息的补充。

语音陪练保留有限的最近对话供模型接着回答；不会提供自动发音分数。对话文字与音频只留在本次运行的内存中，切换语言或退出后释放，不写入学习备份。切换页面会停止录音、播放和进行中的请求。

原「录音跟读」仍是最多 60 秒的本地对比录音，不会因为启用 AI 而自动上传。

## 联网找资料，生成听力

在同页「把感兴趣的主题变成听力题」中：

1. 输入主题，点「联网查资料」。搜索英语或日语维基百科，建议用当前学习语言的关键词，例如 `London`、`Coffee`、`京都`。
2. 选择一条结果，查看摘要和原文链接。
3. 选择入门或进阶，点击「用这份资料生成听力」。主题和所选摘要会发送到你配置的 AI。
4. 预览内容，点击「保存到听力题」。然后可以整篇听、慢速听、答题、交卷看解析或重练错题。

每篇有 3–6 段原文、中文翻译和 3 道四选一题。最多保存 30 篇自建听力；英日材料共用这个容量，随学习备份一起迁移。删除自建材料时，也会删除对应草稿和成绩；操作前可导出备份。内置材料不会被删除。

百科结果是真实联网获取的摘要，生成器不伪造来源。保存的材料保留来源标题、链接、获取时间和 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 改编说明；分享这些改编材料时需保留来源和相同许可。软件源码本身仍为 MIT。搜索和摘要接口见 [MediaWiki REST API](https://www.mediawiki.org/wiki/API:REST_API/Reference) 与 [Page Content Service](https://www.mediawiki.org/wiki/Page_Content_Service)。

维基百科在部分网络中可能无法访问；此时可以取消来源，直接「按主题创作听力」，制作日常学习情景。这类内容会标注为 AI 原创情景。AI 接口本身仍需网络。软件会检查题目的完整性、长度、选项数量和答案范围，但不会自动证明事实或答案正确；使用和分享前请核对原文。

## 密钥、数据与费用

| 点击的操作 | 发给谁 | 发送的内容 |
| --- | --- | --- |
| 测试语音 | 你配置的 API | 密钥、模型/音色、短静音和固定测试文字 |
| 发送消息 / 录音 | 你配置的 API | 密钥、当前消息/录音及最近对话文字 |
| AI 朗读 | 你配置的 API | 密钥、待朗读内容、语言/口音要求 |
| 联网查资料 / 选择资料 | 当前语言的维基百科 | 搜索词或页面标题，不发送 API 密钥和学习记录 |
| 生成听力 | 你配置的 API | 密钥、主题、难度、所选摘要（如有） |

Windows 可选择使用系统 `safeStorage` 加密保存连接，Android 使用 Android Keystore 加密并放在不参与系统自动备份的目录；当前浏览器仅在本次运行持有密钥。只要选择「仅本次使用」并重新测试，先前保存的密钥就会移除；也可直接点击「清除连接密钥」。加密不可用时不退回明文保存。学习备份、学习记录和公开偏好不含 API 密钥。

加密功能依据：[Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)、[Android Keystore](https://developer.android.com/privacy-and-security/keystore) 和 [不参与备份的目录](https://developer.android.com/reference/android/content/Context#getNoBackupFilesDir())。本机加密保护落盘文件；发给服务商的数据如何保存和处理，请以你选择的服务商规则为准。

每次打开软件都需要手动连接测试，不会自动调用 AI。测试、陪练、朗读和生成题目都可能产生 API 费用，由服务商计费。短时间重听同一段朗读会优先使用内存音频缓存，关闭软件后缓存释放。

## 常见问题

- **没有返回有效音频**：检查是否选了真正支持音频输入和输出的模型，及其 WAV 音频对话协议。只有文字说明「我会说话」不能通过。
- **401 / 403 / 404**：分别检查密钥、服务权限或地区限制、根地址或模型名称。
- **429**：可能额度不足或请求过于频繁，检查服务商后台后稍后再试。
- **请求超时**：百科请求约 15 秒、AI 请求约 60 秒后中止；可以重试。手动取消也会中止接收，但服务商仍可能已经处理并计费。
- **AI 朗读未连接**：到「AI 语音」测试，或取消 AI 朗读，继续使用设备音色。
- **生成材料未保存**：模型回复格式不完整、重复选项、内容过长或容量已满时会明确提示，不把坏题目写入学习记录。

本版本已用本机模拟接口检查连接、音频播放、错误拒绝、取消、密钥隔离和听力保存流程；百科搜索另有实际网络检查。未使用用户真实付费密钥验收模型音质、录音识别或口音；Android 真机体验仍需安装后试用。
