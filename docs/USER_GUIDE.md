# 使用听读

## 第一次打开

Windows 下载 ZIP 后完整解压，双击文件夹内的 `听读.exe`，以后直接从这里打开。可创建快捷方式，不能只复制 exe；需要一起保留旁边的运行文件。默认直接进入页面，完整开场动画可以在外观设置中开启。

听读不需要登录账号。首次打开时选择每日单词数和英语口音：可选 5、10、20、30 个，也能自定义 1–100 个；展开日语设置可单独安排日语目标。之后在“调整计划”中修改。

“练今日单词”按当前语言的剩余目标，从未归档词本中安排单词，排除当天已经练过的内容。每天按不同单词计数，重复练习只计一次；正常作答或完成跟读计入，不要求答对。空白作答、直接查看答案和短句不占单词目标。总练习次数和答对率另行统计。

也可以自由选择训练方式、词本和题数。第一次建议 5 题、0.85× 语速，先去“声音与备份”试听。

## 五种训练

| 方式 | 做什么 |
| --- | --- |
| 听写练习 | 听示范后写单词或短句，可选逐题反馈或整组判分 |
| 听音选义 | 听示范，从中文选项中辨认意思 |
| 看义默写 | 看中文，写出原文或日语读音 |
| 阅读辨义 | 看原文，选择中文意思，可听示范和切换日语假名 |
| 录音跟读 | 听示范，再录音并回放比较；只记练习，不自动评分 |

整组听写支持每题朗读 1–3 遍、题间停顿 2 / 4 / 6 / 8 秒，也能单题重听。交卷前确认未填写题目，交卷后统一看答案与错处。未完成练习和输入草稿会保存。

英文判题忽略大小写、多余空格和句末标点，仍区分单词与缺漏字母。日语可练假名读音或标准写法，长音、小假名和促音参与判题；读音模式可统一比较平假名与片假名。标准写法不会自动接受任意同义表达。

看过提示后答对会单独统计，不算独立答对，也不能清除原错题。跟读不计入独立答对率。

## 听力题

从导航进入“听力题”，选择英语或日语。每种语言有 3 篇短对话、3 篇短文，每篇 3 道选择题。点击“播放整篇”后选择答案，可重复播放、慢速听或随时停止；Alt + P 可重听整篇。

所有题目都选好后点击“交卷看解析”。交卷前隐藏原文、翻译和答案；交卷后显示成绩、逐题解释和原文，可按段重听。答错时可选择“只练本组错题”，也能回材料列表选择下一篇。

英语和日语分别保存一组听力草稿，切换语言或关闭程序后可以继续。开始另一组时会提示是否替换已有草稿，已交卷成绩保留。最近 100 组听力成绩随备份保存；听力按题统计，不占每日单词目标，也不影响原来的五种训练。

听力材料由设备语音朗读，英语沿用美式 / 英式设置，日语需要日语音色。题库为原创练习材料，不是录制的真人音频或考试真题。

## AI 语音与联网听力

打开「AI 语音」，填写自己的 API 根地址、密钥、音频模型和音色，点击「保存并测试语音」。通过后可以用文字或录音与 AI 练习英语、日语，也能勾选 AI 朗读。纯文本模型不能通过测试。

联网功能用来搜索维基百科摘要，并生成带来源的听力材料；可预览、保存，之后在「听力题」答题。最多保存 30 篇，随学习备份迁移。也可直接按主题创作日常情景。

AI 陪练录音最多 30 秒，先在本机预听，点击发送才上传。测试和 AI 使用可能产生服务商费用；密钥不进学习备份。配置、兼容协议、隐私和常见错误见 [AI 语音与联网说明](AI_VOICE.md)。

## 美式 / 英式英语与录音

英语页面上方和“声音与备份”都能选择美式或英式英语。试听、单题、整组播放和词本朗读共用这个选择；未完成练习也会采用新设置。

软件只选择真实匹配 `en-US` / `en-GB` 的设备音色，没有时会提示。安装相应系统语音数据后，点“重新检测音色”并试听；Android 还可从应用进入系统语音设置。日语同样需要日语音色。

切换口音只改变朗读，不改变词本原文和判题标准。内置英语音标为美式音标。在线音色可能联网，具体由设备的语音提供方决定。

跟读录音需允许麦克风，每次最多 60 秒。录音只用于当前题目回放，切题、换页面或刷新后释放，不保存到备份，也不上传。

## 自建词本与复习

在“我的词本”选择语言并新建词本。每本选择单词或短句，每行一条，用竖线 `|` 或制表符分隔。

英语示例：

```text
apple | 苹果
Could you say that again? | 可以再说一遍吗？
```

日语示例：

```text
学校 | がっこう | 学校
水をください。 | みずをください | 请给我水。
```

每本有效内容 1–500 条；缺列、重复或过长会显示错误。全项目最多 50 个自建词本，每本含归档词条最多 2000 条。

可修改名称、内容与单词 / 短句类型，也可归档和恢复。修改过的词条会重置相应复习进度，并结束包含它们的未完成练习；未修改词条的进度保留。归档内容不再安排复习，过去作答仍保留。

“错词复习”按原语言、练习方式和日语答案要求安排。独立答对才清除对应错误；连续独立答对后的到期复习间隔为 1、3、7、14 天。

## 配色、夜间和键盘

在“声音与备份”选择四种配色。顶部太阳 / 月亮按钮可直接切换白天与夜间，也可设置跟随系统或定时夜间（19:00–次日 7:00）。

默认快速进入。“完整开场动画”开启后，下次启动显示约 2 秒开场，也可点击或按任意键跳过；系统开启“减少动态效果”时跳过。手机窄屏提供底部导航。

键盘支持 Tab 切换控件、Enter 提交逐题答案、Alt + P 重听、选择题 1–4 或 A–D 作答。整组听写中 Enter 跳到下一题，最后一题才交卷。输入日语时先确认输入法候选字，再提交。看义默写作答前不能用重听暴露答案。

## 保存、备份与迁移

Windows 数据保存在 `%APPDATA%\Tingdu`，当前实际路径也显示在“声音与备份”。移动便携程序文件夹不会自动移动学习数据，从旧单文件版升级也使用原数据目录。Android 保存在应用内部，浏览器保存在当前网址的当前浏览器中。

在“声音与备份”导出 JSON 备份，再在另一端从备份恢复。恢复前会检查格式并显示数量，可撤销上次恢复。备份包含英日进度、自建及归档词本、未完成练习、最近 5000 条单词 / 短句作答，以及英日听力草稿、最近 100 组听力成绩和最多 30 篇自建听力，不含录音、AI 会话和密钥。旧版本备份仍能导入，导入后听力记录从空白开始。不支持自动合并不同设备的记录。

浏览器中的 `localhost` 与 `127.0.0.1` 是不同站点，学习数据分别保存。建议始终用同一入口，切换时先导出备份。

**卸载 Android 应用或清除站点数据前，请先导出备份。** 桌面保存失败或数据损坏时会提示并保留可恢复内容，先导出备份，再排查数据目录；不要用空白数据覆盖原文件。

## 已知验证边界

Windows 包已做启动、保存和包内文件检查，网页已检查白天、夜间与窄屏布局。实际麦克风音质、英式 / 日语声音、Android 真机与模拟器尚未验证；是否可用取决于实际设备权限、WebView 和语音数据。
